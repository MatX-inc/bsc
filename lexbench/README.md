# lexbench — benchmark scaffolding for the Alex lexer switch

**This directory is benchmark scaffolding, intended to be dropped from the
branch before merge.** It documents how the Alex-generated Classic lexer
(now `src/comp/Lex.x`) was validated for token-for-token equivalence with
the previous hand-written String lexer and how the input-representation
choice (strict `Text`) was benchmarked.

See `RESULTS.md` for the full write-up: equivalence methodology (1047/1047
repo `.bs` files token-identical across all variants), lex-only and
end-to-end throughput tables, per-file overhead, allocation/GC analysis,
and the strict-Text-vs-String discussion.

## Layout

- `RESULTS.md` — the write-up.
- `harness/` — standalone benchmark harness. It does not build bsc; it
  compiles the lexer plus its ~20-module dependency closure straight out of
  a bsc checkout with `-i` flags and two shims (`shims/Error.hs`,
  `shims/BuildVersion.hs`).
  - `Main.hs` — driver with `bench` / `dump` / `compare` modes; forces the
    whole token stream via a strict fold (count + order-dependent hash over
    positions and payloads) so laziness cannot fake results.
  - `alexparts/` + `genx.sh` — one shared Alex spec (header template, rules,
    footer) instantiated for five stream types; `genx.sh` assembles
    `gen/*.x` and runs `alex -g` on them.
  - `gen/*.x` — the five assembled variant specs (String, strict/lazy
    ByteString, lazy/strict Text), committed for reading; their `.hs`
    outputs are regenerated by `genx.sh`.
  - `LexAlexShared.hs`, `SmokeTest.hs` — shared support code and a tiny
    build smoke test.
- `bench/hyperfine_e2e*.{json,md,raw.txt}` — hyperfine exports for the
  end-to-end (whole-process) runs, including the corrected re-run
  (`_b` files) whose medians supersede the single-run process table in
  RESULTS.md: hand ≈ 10.6 s vs alex-st ≈ 3.2 s (~3.4x) on the 66 MB file.
- `corpus_utf8.txt` / `corpus_clean.txt` — the corpus file lists (relative
  to a bsc checkout): all UTF-8-valid `.bs` files used for equivalence
  (1047) and the concat-safe subset (1041) used to build the big input.
- `error_files.txt` — the excluded non-UTF-8 (Latin-1) testsuite files.
- `tests/t*.bs` — 10 synthetic edge-case files (Unicode ident/symbol
  classes, tab/CR column rules, line directives, comment forms,
  literal/underscore quirks, escape-position drift).

## Re-running

Requirements: GHC (9.4+), `alex`, and [hyperfine] for the end-to-end runs
(`apt install hyperfine` or `cargo install hyperfine`).

[hyperfine]: https://github.com/sharkdp/hyperfine

```sh
cd lexbench/harness

# 1. generate the five variant lexers
./genx.sh

# 2. build the harness against a bsc checkout (BSC = repo root)
BSC=../..
ghc -O2 -ishims -i$BSC/src/comp -i$BSC/src/comp/Libs -igen \
    -o harness Main.hs -rtsopts

# 3. rebuild the corpus (from the repo root; ~66 MB, not committed)
#    - equivalence corpus: the files listed in ../corpus_utf8.txt
#    - big input: the concat-safe subset repeated 42x
( cd $BSC && for i in $(seq 42); do
    cat $(cat lexbench/corpus_clean.txt); done ) > ../big.bs

# 4. equivalence: every engine must agree token-for-token
./harness compare FILE.bs

# 5. lex-only benchmark (input pre-built outside the timed region)
./harness bench ENGINE ../big.bs 1
#   ENGINE = hand | alex-string | alex-sbs | alex-lbs | alex-lt | alex-st

# 6. end-to-end (whole process) via hyperfine
hyperfine --warmup 1 --export-markdown e2e.md --export-json e2e.json \
  './harness bench hand ../big.bs 1' \
  './harness bench alex-st ../big.bs 1'
```

Notes:

- The harness predates the merge of the lexer into `src/comp/Lex.x`: it was
  written against a tree where `Lex.hs` was the hand-written String lexer
  (its `hand` engine calls `Lex.lexStart` with a `String`). On this branch,
  building it against `src/comp` picks up the Alex lexer as `Lex`, so the
  `hand` engine no longer measures the hand lexer; check out the base
  commit of this branch (or upstream `main`) for a true side-by-side.
- The corpus, generated `gen/*.hs`, binaries, and per-run `.out`/`.rts`
  logs are deliberately not committed.
