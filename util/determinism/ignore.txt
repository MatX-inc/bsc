# bsc determinism gate: the ignore list (util/determinism/compare.py).
#
# Files matching a pattern here are left out of the comparison entirely.  This
# list is only for test-harness noise that is NOT compiler ordering: wall-clock
# text, process addresses, test generators seeded from the clock, GHC RTS
# statistics, the flag's own echo in -print-flags / -v output, the intern-order
# self-test, and binaries.  Anything whose difference comes from Ord Id belongs
# in allowlist.txt, tied to a root, so that it is fixed rather than hidden.
#
# Rules
#  - Every pattern needs a reason (compare.py refuses a line without one) and
#    should be as narrow as the noise: a file, or a suffix within a directory.
#  - Prefer a normaliser to a pattern when the noise is a known line inside an
#    otherwise meaningful file.  compare.py already drops the dated '// On',
#    '// Generated by' and ' * On' header lines and --creation_time lines of
#    .v .sv .cxx .h .c files, the $date section of .vcd files, and replaces
#    0x<hex> addresses in the *.inline-reg / *.no-inline-reg vvp dumps; the
#    clusters new-run-noise-timestamps (.vcd $date, vpi_startup_array.c and the
#    ' * On' lines), new-iverilog-vvp-heap-addresses, the 28 *.vexe.*-reg dumps
#    of new-heap-pointer-noise and the header-only part of none-build-timestamp
#    are therefore left to the normalisers and have no pattern here.
#  - linked-hash-transitive is not noise (a .bo hash that follows an upstream
#    ordering root) and stays in allowlist.txt.
#
# Format: TAB-separated  glob<TAB>reason.  Globs are fnmatch patterns matched
# against the whole path relative to testsuite/ ('*' also crosses '/').

# Binaries and launcher scripts.  archive-pass.sh does not archive these; the
# patterns are a second line of defence (compare.py only warns when a pattern
# matches nothing).
*.vexe	iverilog vvp script: its object labels (S_0x.., v0x.., L_0x..) are iverilog heap addresses; not archived
*.cexe	Bluesim launcher script: carries the --creation_time of its build; not archived
*.syscexe	linked SystemC executable (ELF): link-time layout on top of the .cxx roots tracked in the allow-list; not archived
